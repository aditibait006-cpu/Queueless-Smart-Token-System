# QueueLess: Smart Online Token Management System

**Tagline:** Skip the queue. Save your time.

## About the Project
QueueLess is a web-based token management system designed to help manage queues in colleges and banks. It aims to reduce waiting time and make token handling more organized.

## Services
- **College:** Admission, Certificate Service, Student Office
- **Bank:** Cash Counter, Account Service, Customer Enquiry

## Technologies Used
- **Frontend:** HTML, CSS, JavaScript
- **Backend:** Python with Flask
- **Database:** SQLite
- **Tools:** Visual Studio Code

## Key Features
- Online token booking
- Token number generation
- Token status checking
- Queue management

## How to Run Locally
1. Install Python on your computer.
2. Install the required packages using `pip install -r requirements.txt`.
3. Run the backend using `python app.py`.
4. Open `http://127.0.0.1:5000` in your browser if the Flask application serves the website at that address.

## Project Purpose
QueueLess was developed as an academic field project to demonstrate how a web-based system can organize token management for colleges and banks.
